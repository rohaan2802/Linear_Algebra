Overview

Linear Algebra was taught across several sections in Fall 2024, so the slides, homeworks and solutions came from different instructors and arrived through Google Classroom, WhatsApp and email. This repository keeps all of it together, in the folders I used while studying, so the whole course is easy to revise.

Unit 1

Linear systems

Systems of equations, row reduction, echelon forms, vector and matrix equations, span and linear independence.

Unit 2

Matrices & transformations

Matrix algebra, inverses, elementary matrices, determinants, linear transformations, kernel and range, one-to-one and onto.

Unit 3

Vector spaces & eigenvalues

Subspaces, bases, dimension, change of basis, eigenvalues, diagonalization, difference and differential equations.

Unit 4

Orthogonality & SVD

Inner products, projections, Gram-Schmidt, QR, least squares, symmetric and positive definite matrices, SVD and PCA.

Get the Files

Clone everything with Git, or grab just the part you need.

Clone the repository

Command
git clone https://github.com/rohaan2802/Linear_Algebra.git

Clone without the videos (smaller download)

Command
git clone --filter=blob:limit=5m https://github.com/rohaan2802/Linear_Algebra.git

Download the two large release files

Command
gh release download v1.0 -R rohaan2802/Linear_Algebra

The repository is about 700 MB because of the lecture videos. The filtered clone skips files over 5 MB until you open them.
